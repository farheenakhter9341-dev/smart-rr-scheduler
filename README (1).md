# Smart RR Scheduler Lab
Uniprocessor preemptive Round Robin simulator: Dynamic-Quantum RR + Auto-Tuner for the best fixed quantum.

## Run (Python 3, no installation needed)
    python scheduler.py                 # type processes yourself
    python scheduler.py processes.txt   # read from file (one "arrival burst" per line)
Optional graph: `pip install matplotlib` (saves quantum_graph.png)

## Web version
Open `smart-rr-scheduler.html` in a browser (same algorithm, with charts).

## Files
- scheduler.py: simulator, dynamic quantum rule, auto-tuner, console output
- processes.txt: sample input
- smart-rr-scheduler.html: browser version
