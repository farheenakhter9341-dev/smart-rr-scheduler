How it works

Dynamic quantum rule: at the start of every round, look at the remaining burst times of the processes in the ready queue. If they are similar (spread is small, coefficient of variation below 0.5) use the longest remaining burst, so each job finishes in one turn and no time is wasted switching. If they are very different, use the 75th-percentile burst, so short jobs finish quickly while the quantum is not stretched by one huge job. Quantum = ⌈value⌉, minimum 1. Every process in that round gets the same quantum. If only one process is ready, it runs until the next process arrives, so newcomers are never kept waiting behind a long job. Every process in that round gets the same quantum.
Auto-tuner: runs fixed RR for q = 1, 2, 3 … up to the longest burst and picks the q with the lowest average waiting time (ties go to fewer context switches).
